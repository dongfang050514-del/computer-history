# Computer History · 电脑历史记录

**为电脑留下一份可以回看的日常记录。**

简体中文 · [English](README.en.md) · [日本語](README.ja.md)

Computer History 是一个正在筹备中的个人开源项目，希望以简洁的活动时间线和应用使用统计，帮助你回顾电脑上的一天：用过哪些应用、时间花在哪里，以及何时处理过某件事。

浏览器有历史记录，电脑也可以拥有自己的日常记忆。这是这个小作品的起点。

> 项目状态：概念与设计阶段，尚无可安装版本。下文描述的是产品目标与规划，不代表已经实现的功能。

## 产品理念

- **清楚好看**：以留白、清晰排版和克制的视觉层次呈现信息，减少干扰。
- **安静运行**：平时在后台记录，用户主动打开时再展示，无主动弹窗或声音。
- **轻量优先**：后台记录与界面分离，降低内存、CPU 和磁盘负担。性能指标将在实现后通过实测公布。
- **隐私可控**：以本地存储为默认方向，让用户了解记录范围，并能暂停、排除和删除记录。

## 首版规划

- 应用使用时长：统计前台应用的有效使用时间。
- 每日活动时间线：按时间回看应用切换与使用片段。
- 空闲状态识别：区分使用、离开、锁屏和睡眠时间。
- 托盘控制：暂停、恢复和退出记录。
- 数据管理：排除指定应用，删除记录，设置保留期限。

首版计划优先支持 Windows 10/11。具体兼容范围与资源占用需要开发和测试后确认。

## 隐私边界

规划中的基础记录仅包含应用标识、时间段及空闲状态。默认不采集窗口标题，不截图，不录音，不记录键盘输入内容，不上传活动记录。未来如增加更多记录能力，应提供独立、明确的用户选择。

本地存储并不意味着绝对安全；存储保护、数据清理和日志处理仍需在实现中认真验证。
