# Computer History · パソコンの利用履歴

**パソコンで過ごした一日を、あとから振り返るために。**

[简体中文](README.md) · [English](README.en.md) · 日本語

Computer History は、個人で企画・開発を進めるオープンソースプロジェクトです。アプリの利用時間とシンプルなタイムラインを通じて、何を使い、何に時間をかけ、いつ作業していたかを振り返ることを目指します。

ブラウザーに履歴があるように、パソコンにも日々の記録を。この小さな発想から始まりました。

> 現在は構想・設計段階です。インストール可能なバージョンはまだありません。以下は実装済みの機能ではなく、開発方針と予定です。

## 設計方針

- **見やすさ**：余白と読みやすい文字を大切にした、シンプルな画面。
- **静かな動作**：不要な通知や音を出さず、見たいときだけ画面を開く。
- **軽さ**：記録処理と画面を分離し、メモリ・CPU・ディスクの負荷を抑える。性能は実装後に測定して公開する。
- **利用者の管理**：ローカル保存を基本に、記録の一時停止、対象外アプリの指定、削除を可能にする。

## 初期バージョンの予定

- 前面で使用しているアプリの利用時間集計。
- 一日のアプリ利用タイムライン。
- アイドル、画面ロック、スリープの識別。
- トレイからの一時停止、再開、終了。
- アプリの除外、履歴の削除、保存期間の設定。

まず Windows 10/11 を対象とします。対応環境とリソース使用量は、実装と検証を通じて確認します。

## プライバシー

基本の記録対象は、アプリの識別情報、時間帯、アイドル状態を予定しています。ウィンドウタイトルは初期設定では収集しません。スクリーンショット、録音、キー入力内容の記録、活動履歴のアップロードは基本機能の対象外です。将来対象を広げる場合は、利用者が個別に明示的な選択をできる設計にします。

ローカル保存だけで完全な安全性を保証することはできません。保存データの保護、削除処理、ログの扱いも検証が必要です。
